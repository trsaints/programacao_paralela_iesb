# Gráficos comparativos e gerais

Versione aqui os gráficos que comparam implementações ou acompanham os
relatórios gerais: tempo, speedup, eficiência e escalabilidades forte/fraca.

Os gráficos exclusivos de uma implementação pertencem a
`baseline/graficos/`, `openmp/graficos/` ou `mpi/graficos/`. Use somente dados
válidos obtidos no ambiente oficial e mantenha o CSV de origem versionado.
