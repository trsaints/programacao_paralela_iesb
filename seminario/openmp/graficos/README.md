# Gráficos da versão OpenMP

Após uma campanha validada, `../../script_analise.py --campanha forte` gera em
`forte/` os gráficos de tempo, speedup e eficiência. O comando
`../../script_analise.py --campanha fraca` gera em `fraca/` os gráficos de
tempo, tempo relativo e eficiência fraca. Os CSVs de origem são gerados em
`../dados/<campanha>/` por `script_medicao.py`.
