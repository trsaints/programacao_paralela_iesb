# Dados compartilhados da campanha

- `metricas.csv`: comparação por implementação, tamanho e número de unidades;
  contém `T1`, `Tp`, speedup e eficiência.
- `execucoes_ignoradas.csv`: versões que não puderam participar da campanha e
  o motivo registrado pelo script.

Os dados brutos e resumos pertencem à pasta `dados/` da respectiva
implementação. Consulte `../README.md` para o protocolo de medição e a
proveniência dos dados atualmente versionados.
