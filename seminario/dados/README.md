# Dados compartilhados das campanhas

- `forte/metricas.csv`: `T1`, `Tp`, speedup e eficiência para tamanhos fixos.
- `fraca/metricas.csv`: tempo relativo e eficiência fraca para trabalho por
  unidade aproximadamente constante.
- `<campanha>/execucoes_ignoradas.csv`: versões que não puderam participar e o
  motivo registrado pelo script.

Os dados brutos e resumos pertencem à pasta `dados/` da respectiva
implementação, separados em `forte/` e `fraca/`. Consulte `../README.md` para
o protocolo de medição.
